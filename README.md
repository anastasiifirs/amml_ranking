# AMML ranking 2026 — решение и журнал экспериментов

Задача: ранжирование русскоязычных фрагментов по запросу, метрика — средний по запросам NDCG@10.

**Итог:** OOF NDCG@10 0.9659 (5 фолдов), Public 0.9615 — сабмит 06.

**Запуск:** `solution.ipynb` в Kaggle Notebook (Linux, Python 3.13, GPU T4 x2, интернет включён для скачивания весов с HuggingFace, подключены данные соревнования), Run All. Версии пакетов — `requirements.txt`. Время ≈ 9 ч 45 мин (лимит Kaggle — 12 ч). Результат — `submission.csv`.

## Итоговая схема

1. **Чистка.** Ударения (U+0301), латинские буквы-двойники в русских словах («Cписок» → «Список»), двойное HTML-экранирование (`&lt;p&gt;`) и теги, префикс «Навигация: Главная | Статьи», неразрывные/тонкие пробелы; `article_char_count` из строк вида `3 646,0` в число.
2. **Лексические признаки и метаданные.** Леммы (pymorphy3) без стоп-слов: пересечение запроса с текстом/заголовком, BM25 по фрагменту и по заголовку, косинусы TF-IDF (леммы 1–2-граммы, символьные 3–5-граммы); позиция фрагмента в статье и её доля, длина статьи и фрагмента, число фрагментов той же статьи в выдаче запроса, частота документа/статьи по запросам; ранги и отставание от максимума внутри запроса.
3. **Нейро-признаки (уровень 1).**
   - без дообучения: косинус [`deepvk/USER-bge-m3`](https://huggingface.co/deepvk/USER-bge-m3); скор [`BAAI/bge-reranker-v2-m3`](https://huggingface.co/BAAI/bge-reranker-v2-m3); скор [`jinaai/jina-reranker-v2-base-multilingual`](https://huggingface.co/jinaai/jina-reranker-v2-base-multilingual) (fp16; модель со своим кодом — `trust_remote_code`, ревизия репозитория на момент прогона `9cfeff2df7d40d1b78e75e5e9cebec92a99813c9`; этот код импортирует из transformers 4.x функцию, удалённую в 5.x, — `ce.load_ce` возвращает её без изменений, скоры совпадают с прогоном на transformers 4.57); скор [`Qwen/Qwen3-Reranker-8B`](https://huggingface.co/Qwen/Qwen3-Reranker-8B) (родной промпт yes/no, скор = logit(yes) − logit(no), fp16, модель разрезана на 2 GPU);
   - **дообученные на train** `bge-reranker-v2-m3` (1 эпоха, lr 2e-5, max_len 512, fp16): **listwise** — шаг = 2 запроса целиком (≤12 кандидатов: все релевантные + случайные нерелевантные), лосс BCE + softmax-кросс-энтропия по кандидатам запроса, 2 seed; **BCE по парам** — батч 16 из текстов близкой длины, 1 seed. Для train — out-of-fold (модель фолда k скорит только фолд k), для test — среднее пяти моделей.
   - для каждого нейро-скора — признаки относительно статьи и запроса: максимум по фрагментам той же статьи в выдаче, ранг внутри статьи, z-score внутри запроса.
4. **Уровень 2.** LightGBM lambdarank (lr 0.02, 15 листьев, 600 итераций, 3 seed) и CatBoost YetiRank на всех признаках, те же 5 фолдов; финал — среднее перцентильных рангов внутри запроса.

Открытые датасеты не используются: дообучение — только на `train.csv`.

## Валидация

5 фолдов по md5(`query_id`) % 5 (группы по запросу; не зависит от версии sklearn) (запросы не пересекаются между фолдами, как train/test); метрика реализована 1:1 с Kaggle (сортировка по скору, при равенстве — по id, IDCG по всем кандидатам). Одно и то же разбиение на обоих уровнях, чтобы OOF-скоры реранкера не протекали в ранжировщик.

## Наблюдения EDA

- **Ударения (U+0301)** — в 23% запросов и 9% фрагментов (в основном первые абзацы статей). Ломают лемматизацию (pymorphy3 не узнаёт «Педера́стия») и токенизацию нейромоделей («це», «́», «р»…). Снятие ударений: BM25 0.674 → 0.711, TF-IDF символьный 0.695 → 0.711. При этом наличие ударения во фрагменте — сигнал: в запросах без ударений такие фрагменты релевантны в 48% случаев против 26%; флаги ударений считаются до чистки и идут признаками.
- **Латинские буквы-двойники в русских словах** («Cписок», «Макcимовной», «ATФ», «eё») — 314 фрагментов (0.7%). Исправляются только в словах с кириллицей, где все латинские буквы имеют кириллический двойник («Boeing», «iPhone» не трогаются).
- Несогласованные метаданные: у 1.5% строк `passage_index` ≥ `article_passage_count`; у 1–2% статей разные заголовки/число фрагментов в разных строках; 7 одинаковых текстов с разными `document_id`.

- train: 31 530 пар / 3 042 запроса, test: 13 507 / 1 305; ~10 кандидатов на запрос, в каждом ≥1 релевантный, доля релевантных 0.26.
- Шум в текстах (HTML, экранирование, навигационный префикс, пустые заголовки ~5%, пропуски метаданных 4–9%, нестандартный формат чисел) равномерен по `ingest_source` S0–S3; доля релевантных по источникам одинакова (~0.25–0.26).
- Запросы и фрагменты train/test не пересекаются, часть статей общая.
- Метаданные сильно информативны: первый фрагмент статьи релевантен чаще (0.34 против ~0.23), а релевантность зависит от числа фрагментов той же статьи в выдаче.
